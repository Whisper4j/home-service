### 1. auth_account-账号表

保存客户、服务人员和管理员的登录账号、角色、启停状态及公共联系资料。

| 字段名 | 数据类型 | 中文说明 | 备注 |
| ------ | -------- | -------- | ---- |
| id | bigint | 认证账号ID，对外按十进制字符串传输 | 主键；自增；非空；CUSTOMER账号的客户ID也使用此值；JWT主体使用账号ID |
| username | varchar(32) | 登录用户名，区分大小写 | 非空；区分大小写；唯一：`uk_auth_account_username(username)` |
| password_hash | varchar(60) | BCrypt哈希，不保存明文密码 | 非空；区分大小写 |
| role | varchar(16) | 角色：CUSTOMER/WORKER/ADMIN | 非空；区分大小写；CUSTOMER=客户；WORKER=服务人员；ADMIN=管理员 |
| status | varchar(16) | 状态 | 非空；默认'ENABLED'；区分大小写；ENABLED=启用；DISABLED=禁用 |
| display_name | varchar(40) | 展示称呼 | 非空 |
| phone | char(11) | 联系电话 | 非空；区分大小写 |
| protected_account | tinyint | 是否为禁止禁用的初始化管理员 | 非空；默认0；0否，1是 |
| created_at | datetime | 创建时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| updated_at | datetime | 更新时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP；更新时自动刷新 |

**索引：**

唯一索引：`uk_auth_account_username`，字段：`(username)`，保证登录用户名不重复。

### 2. administrative_region-行政区表

保存省、市、区的层级关系及可服务区域。

| 字段名 | 数据类型 | 中文说明 | 备注 |
| ------ | -------- | -------- | ---- |
| code | varchar(6) | 国家统计局行政区划代码 | 主键；不自增；非空；区分大小写 |
| parent_code | varchar(6) | 上级行政区代码 | 可为空；逻辑关联→administrative_region.code；区分大小写 |
| name | varchar(40) | 行政区名称 | 非空 |
| level | varchar(16) | 级别：PROVINCE/CITY/DISTRICT | 非空；区分大小写；PROVINCE=省；CITY=市；DISTRICT=区县 |
| service_enabled | tinyint | 是否属于当前服务区域 | 非空；默认1；0否，1是 |
| sort_no | int | 展示顺序 | 非空；默认0 |
| created_at | datetime | 创建时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| updated_at | datetime | 更新时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP；更新时自动刷新 |

### 3. worker_profile-服务人员表

保存服务人员的服务城市、调度开关和统一排班模板。姓名、电话及登录凭证关联账号表。

| 字段名 | 数据类型 | 中文说明 | 备注 |
| ------ | -------- | -------- | ---- |
| id | bigint | 服务人员业务ID，与认证账号ID相互独立 | 主键；自增；非空 |
| account_id | bigint | 认证账号ID | 非空；逻辑关联→auth_account.id；必须为WORKER角色；唯一：`uk_worker_profile_account(account_id)` |
| city_code | varchar(6) | 服务城市代码 | 非空；逻辑关联→administrative_region.code；区分大小写 |
| dispatch_enabled | tinyint | 是否允许新的派单和抢单 | 非空；默认1；0否，1是 |
| work_intervals | json | 每日工作区间；未设置排班时为空 | 可为空；JSON对象数组，1—14个区间；结构如[{"start":"08:00","end":"12:00"}]；HH:mm格式，30分钟对齐，08:00≤start<end≤22:00且不重叠；与rest_weekdays同时为SQL NULL表示未配置 |
| rest_weekdays | json | 每周休息日；1周一至7周日，未设置时为空 | 可为空；JSON整数数组，元素为1周一至7周日且不重复；[]表示无固定休息日；与work_intervals同时为SQL NULL表示未配置 |
| created_at | datetime | 创建时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| updated_at | datetime | 更新时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP；更新时自动刷新 |

**索引：**

唯一索引：`uk_worker_profile_account`，字段：`(account_id)`，保证一个服务人员账号最多对应一条人员资料。

保存客户的联系人、联系电话、地址及默认标记，支持多地址管理。

| 字段名 | 数据类型 | 中文说明 | 备注 |

| contact_name | varchar(40) | 地址簿联系人 | 非空 |
| contact_phone | char(11) | 地址簿联系电话 | 非空；区分大小写 |
| province_code | varchar(6) | 省代码 | 非空；逻辑关联→administrative_region.code；区分大小写 |
| province_name | varchar(40) | 省名称快照 | 非空 |
| city_code | varchar(6) | 市代码 | 非空；逻辑关联→administrative_region.code；区分大小写 |
| city_name | varchar(40) | 市名称快照 | 非空 |
| district_code | varchar(6) | 区代码 | 非空；逻辑关联→administrative_region.code；区分大小写 |
| district_name | varchar(40) | 区名称快照 | 非空 |
| detail | varchar(200) | 详细地址 | 非空 |
| longitude | decimal(10,7) | 系统解析经度，未解析时为空 | 可为空 |
| latitude | decimal(9,7) | 系统解析纬度，未解析时为空 | 可为空 |
| is_default | tinyint | 是否为默认地址 | 非空；默认0；0否，1是；有有效地址时其中一个为默认地址 |
| deleted_at | datetime | 逻辑删除时间；历史订单使用独立快照 | 可为空 |
| created_at | datetime | 创建时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| updated_at | datetime | 更新时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP；更新时自动刷新 |

### 9. service_sku-服务规格表

保存可预约服务规格的价格、时长、服务内容及入口绑定。

| 字段名 | 数据类型 | 中文说明 | 备注 |
| ------ | -------- | -------- | ---- |
| id | bigint | 服务规格SKU ID | 主键；自增；非空 |
| item_id | bigint | 服务项目ID | 非空；逻辑关联→service_item.id |
| name | varchar(80) | 规格名称 | 非空 |
| standard_price | decimal(11,2) | 标准价，范围与OpenAPI Money一致 | 非空 |
| minimum_offer_price | decimal(11,2) | 最低优惠报价；不支持优惠时等于标准价 | 非空 |
| duration_minutes | smallint unsigned | 预计服务分钟数，30分钟整数倍 | 非空；30—720分钟，30的整数倍 |
| unit | varchar(20) | 计价单位展示文案 | 非空 |
| status | varchar(16) | 状态 | 非空；默认'OFF_SHELF'；区分大小写；ON_SHELF=上架；OFF_SHELF=下架 |
| supports_offer | tinyint | 是否支持优惠预约 | 非空；默认0；0否，1是 |
| description | varchar(2000) | 服务说明 | 非空 |
| included | varchar(1000) | 包含内容 | 非空 |
| excluded | varchar(1000) | 不包含内容 | 非空 |
| customer_supplies_parts | tinyint | 是否由客户自备配件 | 非空；默认0；0否，1是 |
| client_entry_code | varchar(64) | 绑定的客户端入口编码 | 可为空；逻辑关联→client_entry.code；区分大小写；NULL表示未绑定，允许多个NULL；不使用空字符串；下架保留绑定，逻辑删除清空绑定；唯一：`uk_service_sku_client_entry(client_entry_code)` |
| deleted_at | datetime | 逻辑删除时间 | 可为空 |
| created_at | datetime | 创建时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| updated_at | datetime | 更新时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP；更新时自动刷新 |

**索引：**

唯一索引：`uk_service_sku_client_entry`，字段：`(client_entry_code)`，保证同一个非空客户端入口最多绑定一个服务规格，允许多条记录不绑定入口。

### 27. http_idempotency_record-幂等请求表

保存幂等写请求的作用域、请求指纹、执行状态及成功响应。

| 字段名 | 数据类型 | 中文说明 | 备注 |
| ------ | -------- | -------- | ---- |
| id | bigint | HTTP幂等记录ID | 主键；自增；非空 |
| scope_type | varchar(24) | 作用域类型 | 非空；区分大小写；ACCOUNT=账号；ANONYMOUS_REGISTER=匿名注册 |
| account_id | bigint | 认证账号作用域的账号ID | 可为空；逻辑关联→auth_account.id |
| anonymous_subject_hash | char(64) | 匿名注册使用规范化用户名SHA-256，不保存密码或完整请求 | 可为空；区分大小写 |
| scope_identity | varchar(90) | 幂等作用域标识 | 存储生成列，可空定义；有效作用域由CHECK保证非空；值为ACCOUNT:账号ID或ANON_REGISTER:用户名摘要；不手动赋值；区分大小写；联合唯一：`uk_http_idempotency_scope(scope_identity, http_method, request_path, idempotency_key)` |
| http_method | varchar(10) | 大写HTTP方法 | 非空；区分大小写；POST=创建或动作；PUT=整体更新；PATCH=部分更新；DELETE=删除；联合唯一：`uk_http_idempotency_scope(scope_identity, http_method, request_path, idempotency_key)` |
| request_path | varchar(255) | 不含查询串的规范化接口路径 | 非空；区分大小写；联合唯一：`uk_http_idempotency_scope(scope_identity, http_method, request_path, idempotency_key)` |
| idempotency_key | varchar(128) | 请求幂等键 | 非空；区分大小写；8—128位字母、数字、下划线或短横线；联合唯一：`uk_http_idempotency_scope(scope_identity, http_method, request_path, idempotency_key)` |
| request_fingerprint | char(64) | 规范化请求指纹 | 非空；64位十六进制摘要；敏感内容使用HMAC-SHA-256，不保存原文；区分大小写 |
| execution_status | varchar(16) | 执行状态 | 非空；默认'PROCESSING'；区分大小写；PROCESSING=处理中；SUCCEEDED=成功 |
| response_http_status | smallint unsigned | 成功响应HTTP状态码 | 可为空 |
| response_content_type | varchar(64) | 成功响应Content-Type | 可为空；区分大小写 |
| response_json | json | 成功响应必要快照；不包含密码、令牌或无关敏感字段 | 可为空；JSON对象，保存首次成功响应的code、message、data；PROCESSING时为空，SUCCEEDED时非空；不含密码或令牌 |
| expires_at | datetime | 幂等记录过期时间，至少保留24小时 | 非空 |
| created_at | datetime | 开始执行时间（Asia/Shanghai） | 非空；默认CURRENT_TIMESTAMP |
| completed_at | datetime | 成功完成时间（Asia/Shanghai） | 可为空 |

**索引：**

唯一索引：`uk_http_idempotency_scope`，字段：`(scope_identity, http_method, request_path, idempotency_key)`，保证同一幂等作用域、HTTP方法和请求路径下的幂等键不重复。
