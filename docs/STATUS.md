## 已完成

- 删除运行时 Mock 数据库、状态机、调度、排班、支付、并发、图片存储及到期任务；删除模式切换、演示账号密码、工具页面、时间推进和故障模拟。源码不再使用 localStorage/IndexedDB/Web Locks/BroadcastChannel 承担业务数据或事务。
- API 始终使用同源 /api，WebSocket 使用同源 /ws，保留 Bearer Token、AUTH 首帧、幂等键、统一错误及自动同步；失败不回退成功。业务数据由 HTTP 返回，sessionStorage 仅保留会话和隔离的草稿、幂等及导航上下文。
- 首页、服务分组和详情从 listClientEntries 渲染；不保留固定入口注册表或服务价格。新增管理员入口查询供 SKU 表单使用。服务地区、工作区间、时间粒度、上传限制、报价步长等读取接口。
- ClientEntryCode 为受约束字符串；SkuDTO.clientEntryCode 为必传可空字段，创建和更新明确发送绑定字符串或 null。分类、项目、SKU、技能查询模型拆分，公开目录没有 status 参数。
- 移除 OfferPriceRule 和 offerPriceRule，统一使用接口 priceStep 的整数倍规则；报价组件保留非法输入反馈、合法边界、差额确认、幂等及价格冲突处理，不保留旧浏览器订单兼容分支。
- 新增 OrderStatusHistoryVO 和必需 statusHistory；AssignmentVO 补充分配释放/完成信息；AuditTargetType 与 AuditVO.orderId 明确审计目标及订单关联。三端详情按接口权限展示历史，不展示内部操作者账号ID。OrderVO.allowedActions 由后端计算，前端不自行决定订单操作权限。
- 保留三端低保真布局、预约表单、资料/地址面板、图片鉴权请求、人员任务/抢单池、月历及管理能力。管理员仍无手工派单或改派入口。
- 删除依赖浏览器数据库或拦截接口的旧测试；新增纯函数边界及静态契约测试，真实端到端入口必须显式配置 E2E_BASE_URL，不提供替代后端数据。
