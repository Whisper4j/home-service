- 保留27个原有主键及实体身份设计；移除全部47个普通查询二级索引，最终保留14个额外唯一索引。12个唯一索引不变，入口绑定和订单分配改为普通字段上的唯一约束，默认地址辅助唯一约束和图片排序唯一约束已移除。

- 采用逻辑外键，不新增物理外键或替代性能设施。保留既有金额、时间、枚举、88个CHECK及幂等作用域模型，仅移除指定的三个辅助生成列。
