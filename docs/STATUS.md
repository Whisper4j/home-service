# 当前状态

更新时间：2026-10-04

## 当前阶段

三端低保真产品原型与正式接口契约已完成本次交互完善，可用于产品演示和后续前后端联调。工作仍在现有 `home-service-web` 内进行，没有创建后端工程、数据库表或迁移脚本。浏览器 Mock 成功不代表真实后端已实现。

## 契约与工程

- `docs/api/openapi.yaml` 是唯一正式接口契约，OpenAPI 3.0.3，85个 HTTP 操作、144个 Schema；同文件定义 `/ws` 认证首帧及通知事件。保留 JWT、三端权限、统一响应、分页、字符串错误码与 ID、两位小数字符串金额、Asia/Shanghai 时间、幂等和报价版本校验。
- Vue 3 + Vite + TypeScript + npm 标准工程；类型、请求路由元数据和 Mock 校验 Schema 从契约生成。默认 Mock，`VITE_USE_MOCK=false` 使用同源 `/api`、`/ws`，连接失败正常报错，不回退为 Mock。没有硬编码本机后端地址。
- 客户地址写入 DTO 不再接收经纬度；返回 VO 仍含系统维护、可为空的坐标。当前不接地图、不伪造坐标，空坐标可按广州市范围预约。仅改联系人/电话/默认标记保留系统坐标；实际地址变化后坐标失效为空。
- 订单使用独立 `OrderAddressSnapshotVO`，地址簿、个人信息和未来坐标更新均不改变历史订单。已有 Mock 数据兼容补齐而不整体重置；旧订单缺少入池时间时从原始支付流水补齐，历史关闭时间的演示迁移仍不代表真实后端审计。

## 客户端

- 保留随视口变化的竖屏布局，顶部和底部稳定，中间独立滚动；固定清洁/维修入口、清洁弹窗、日常/深度切换、套餐详情、维修分类与项目流程均保留。入口通过 `clientEntryCode` 显式关联正式 SKU；新增后台分类不改变首页，缺失或下架明确不可预约。
- 预约支持默认/切换/新增地址、独立本次联系人、半小时时间、结束时间、备注和至多3张现场图片。我的与预约复用地址面板，列表和编辑在同一面板切换，新地址保存后选中，保留报价、时间、手动联系人、备注和图片草稿。
- 默认地址唯一；首个地址自动默认，删除或取消默认后最早添加的其他地址成为默认。个人资料、地址联系人和本次订单联系人各自独立，修改不无提示覆盖。
- 我的直接显示称呼与登录状态，点击称呼在资料弹窗查看，使用“✎ 编辑信息”切换编辑称呼/联系电话，账号只读。地址簿、预约说明为紧凑面板入口，退出须确认。旧资料、地址、规则链接兼容到对应面板；未登录操作会登录回跳。
- 新订单报价为5元整数倍，不低于最低价且严格低于标准价；最低价向上取合法值，无合法范围则关闭优惠能力。建议价取中点向下对齐后限制在合法区间；历史订单保留最低价锚点规则快照。初始报价与调价共用组件，非法输入不静默修正、边界禁用、无变化不可提交。
- 优惠调价保持来源状态、截止、模拟补付/退款、幂等和版本规则。报价冲突保留原报价与最新报价，必须重新确认；接单后锁价，不自动转标准、不自动加价。维修只支持标准预约，优惠预约至少提前12小时。
- 创建成功提示“预约已提交，请在15分钟内支付”，进入独立模拟支付页。支付成功与安排成功分别说明；明确失败保留原因，响应丢失持续显示正在确认，通过 HTTP 查询或同幂等键重试，刷新保留不确定状态与操作键。
- 支付结果自动同步安排/抢单/取消退款。顶部按本次合法业务来源回日常套餐、深度套餐或维修项目列表；来源按账号和订单保存，刷新可恢复，未知来源首页兜底且不接受外部跳转。底部另有返回首页、查看订单进度；未支付退出仍回待支付详情。
- 客户与人员共用紧凑单行订单分组，窄屏横向滚动标签，不撑宽页面；分组不合并正式状态。详情返回恢复筛选、页码和列表位置。保留支付历史、报价历史、客户开始码、状态限制下取消、确认完成和每单一次评价。

## 服务人员端

- 首页上方优先任务和下一单摘要，全部任务近全屏展开并恢复池位置。标准派单直接进入任务，无接受/拒绝步骤；自主抢单保留来源标识。
- 抢单池完整资格过滤后固定按支付成功首次入池时间升序，同时间按数值意义字符串 ID 升序，再分页；比较大整数不损失精度。调价不改变发布时间，排序选择器及旧排序参数已移除。
- 新单自动加入全局后部，失效订单自动移除并补位；按顺序分批展示，不跳过旧单。同步保留阅读锚点，通知合并、去重，按下点击期间延后卡片重排，确认窗口冻结原报价与版本；已知不可接状态持续禁用，HTTP决定唯一结果。
- 沿用 `/ws` 通知和 Mock 跨标签页业务事件；约30秒可见页面 HTTP 补漏，恢复可见、网络恢复、连接重建后重查。合并并发请求，离页清理监听/定时器，局部失败保留数据，正常页面没有刷新池或点击加入新单按钮，异常提供重试连接。不声称支持手机后台推送。
- 我的直接显示姓名、身份、今日待服务/本月完成/累计完成文字摘要、工作时间与请假按钮及月历。统计来自完整聚合接口，使用北京时间与实际完成确认时间，不含待确认，不把订单金额当人员收入，Mock明确为演示聚合。
- 资料弹窗仅电话可编辑，姓名、账号、技能、城市、状态与调度资格只读。工作时间、请假、分页记录、服务规则及退出确认均使用面板。旧 profile/statistics/schedule/rules 链接兼容到我的及对应内容，已移除重复页面实现。
- 月历沿用未来30天查看窗口和统一每日区间/每周固定休息日模型，直接展示合并的服务、缓冲、请假及工作时间内空闲；不将缓冲当空闲，不保证任意服务可接。请假至少提前2小时、半小时粒度，不能覆盖服务或缓冲；冲突可查看本人订单，返回保留日历选择与草稿。
- 人员订单仍在全量排序后分页：进行中、待服务、待确认、历史，历史按实际关闭时间倒序。顺序履约、客户提供开始码、提交完成待客户确认及24小时自动完成保留，人员无取消或改价权限。

## 共用反馈、弹窗与权限

- 三端普通成功和错误使用同一内容顶部浮层，2秒消失且不堆叠，弹窗打开时仍可见。字段在失焦/提交时验证，错误保留至修正；报价冲突、支付不确定、退款与安排结果在正文保留。
- 弹窗锁定背景滚动，关闭恢复位置；长正文内部滚动，操作栏可到达，适应窄屏、长姓名/地址及视口缩短。只有真正未保存修改才确认放弃，同一面板切换查看/编辑。浏览器正常返回关闭面板或回业务上层，无全局拦截。
- 草稿按角色/账号隔离，登录过期保留安全恢复上下文，其他账号不读取原账号草稿。自动同步不覆盖输入和确认价格。
- 现场图片仍限制 JPEG/PNG/WebP、最多3张、每张5 MiB，支持选择、预览、删除、失败重试及历史查看。上传前清理元数据；图片内容在 Mock IndexedDB、业务引用在 localStorage。HTTP模式保留 multipart 上传及鉴权图片读取契约。
- 图片按本人、已分配人员或仍有接单资格人员、关联订单管理员进行访问控制，不提供公开 URL 或公开列表。抢单前隐藏结构化门牌、电话和开始码；图片不保证接单、不扩大服务范围、不允许现场议价。
- 管理员保留目录、账号、人员、配置、审计、支付退款、调度及异常取消功能，本次只应用共用反馈及契约必要配套，不增加手工派单。
